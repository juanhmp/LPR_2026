## 📚 Conteúdo das Aulas

### 🧠 Aula 02 - Introdução à Lógica de Programação

Nesta aula foram trabalhados os conceitos iniciais necessários para o desenvolvimento de programas.

**Conteúdos abordados:**

- Tipos de dados
- Variáveis e constantes
- Operadores
- Entrada e saída de dados
- Primeiros algoritmos

---

### 🌐 Aula 03 - Git e GitHub

Introdução às ferramentas utilizadas para controle de versão e armazenamento de projetos.

**Conteúdos abordados:**

- Conceitos de Git e GitHub
- Criação de repositórios
- Commits
- Branches
- Merge
- Principais comandos de versionamento

---

### 🔀 Aula 04 - Estruturas de Seleção

Estudo das estruturas utilizadas para controlar decisões durante a execução de um programa.

**Conteúdos abordados:**

- `if`
- `else if`
- `switch`
- Operadores relacionais e lógicos
- Tomada de decisão

---

### 🔁 Aula 05 - Estruturas de Repetição

Utilização de estruturas responsáveis pela repetição de instruções.

**Conteúdos abordados:**

- `for`
- `while`
- `do while`
- Controle de laços
- Repetição de instruções

---

### ⚙️ Aula 06 - Funções

Estudo da criação e utilização de funções para melhorar a organização dos programas.

**Conteúdos abordados:**

- Criação de funções
- Parâmetros
- Retorno de valores
- Organização e reutilização de código

---

### 📊 Aula 07 - Vetores e Matrizes

Utilização de estruturas capazes de armazenar e organizar conjuntos de informações.

**Conteúdos abordados:**

- Vetores
- Matrizes
- Percorrendo estruturas
- Manipulação de dados

---

### 🧩 Aula 08 - Structs

Estudo de estruturas utilizadas para agrupar diferentes informações em uma única organização.

**Conteúdos abordados:**

- Estruturas (`struct`)
- Organização de dados
- Agrupamento de diferentes tipos de informações

---

### 📋 Aula 09 - Listas e Dicionários

Utilização de coleções para armazenar e manipular informações de maneira dinâmica.

**Conteúdos abordados:**

- Listas e vetores dinâmicos
- Manipulação de elementos
- Dicionários
- Inferência de tipos com `var` (C#) e `auto` (C++)
